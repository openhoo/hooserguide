01

Die erste Aufgabe anlegen

Legen Sie eine Aufgabe an. Prüfen Sie nach dem Neuladen, ob Titel und Priorität weiterhin in der Liste stehen.

Voraussetzungen

  • Öffnen Sie Ihren Arbeitsbereich mit der Berechtigung, Aufgaben anzulegen.
Tipp

Verwenden Sie einen kurzen Titel, der den nächsten Arbeitsschritt beschreibt.

  1. Geben Sie einen eindeutigen Aufgabentitel ein und wählen Sie die Priorität.
  2. Wählen Sie Create task. Prüfen Sie, ob die Aufgabe in der Liste und eine Bestätigung erscheinen.
  3. Laden Sie die Seite neu. Prüfen Sie unter Upcoming tasks, ob Titel und Priorität Ihrer Aufgabe unverändert sind.
02

Benachrichtigungen anpassen

Legen Sie für diese Browsersitzung fest, ob Sie E-Mail-Benachrichtigungen erhalten möchten.

Hinweis

Einstellungen werden getrennt von den einzelnen Aufgaben gespeichert.

Warnung

Aktivieren Sie E-Mail-Benachrichtigungen nur für ein Konto, das Sie kontrollieren.

  1. Scrollen Sie unter die Aufgabenliste zu Workspace preferences. Aktivieren Sie Email notifications und wählen Sie Save preferences.
  2. Unter der Schaltfläche erscheint die Meldung „Preferences saved.“
